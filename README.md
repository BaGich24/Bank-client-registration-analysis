# Анализ процесса регистрации клиентов в банке

## 📊 Описание проекта

Этот проект содержит подробный анализ данных по процессу регистрации новых клиентов (физических лиц) в отделениях банка за первые 7 месяцев 2024 года.

### 🎯 Цель

- Визуализировать динамику процесса регистрации
- Выявить проблемные зоны и узкие места в процессе
- Оценить изменения показателей за анализируемый период
- Предоставить инсайты для улучшения процесса

## 🔍 Что включено

- **Статистический анализ** событий регистрации
- **Временные ряды** и тренды процесса
- **Визуализации** ключевых метрик
- **Сегментация данных** по отделениям и периодам
- **Выявление аномалий** и критических моментов

## 📋 Требования

- Python 3.8+
- pandas
- numpy
- matplotlib
- seaborn

Все зависимости указаны в файле `requirements.txt`

## 🚀 Установка и использование

### 1. Клонируйте репозиторий
```bash
git clone https://github.com/yourusername/bank-client-registration-analysis.git
cd bank-client-registration-analysis
```

### 2. Установите зависимости
```bash
pip install -r requirements.txt
```

### 3. Откройте Jupyter Notebook
```bash
jupyter notebook analysis.ipynb
```
